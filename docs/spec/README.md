# Spec

The behaviour-only spec for the randomizer: what it must do, the in-game
hazards and the outcomes required. It was written by a separate person who
read the reference program, then reviewed for contamination (no code, no
identifiers, no data tables) before it was committed here. Upstream citations
were stripped.

Build from this, never from the reference (see `PLAN.md` §1). Where the spec
says *tuned upstream, choose our own*, pick and document our own value. Where
it is unclear, ask for the spec to be extended.

Start with `00-overview.md`. The facts we must derive ourselves are listed in
`10-open-questions.md`.
