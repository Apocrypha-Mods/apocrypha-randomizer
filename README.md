# Apocrypha Randomizer

An original item and enemy randomizer for Elden Ring, in Rust, for Linux,
Windows and macOS. Free software under the GNU GPL, version 3 or any later
version: see [LICENSE](LICENSE).

Kraken decoding uses [`oozextract`](https://github.com/lvlvllvlvllvlvl/oozextract), a Rust
port of [`ooz`](https://github.com/powzix/ooz) (GPL-3.0-or-later, Copyright (C) 2016 Powzix).
No game files are in this repository; the tool reads them from the player's own install.

Start with [PLAN.md](PLAN.md). It covers the clean-room rules, which every
contributor must follow before reading or writing any code here.
